## Repository and source baseline

Original main was cloned at `f5f355e` (Add automated game logic tests).
The implementation branch is `feature/ios-native`. The Python source, artwork,
and Python workflow are preserved. No modifications are made to the old
checkout previously reported at `C:\Users\daniy\Coding\MATHRONAUTS`.

The audited source is `U11-Final CPT.py`:

- Addition operands 1...25; subtraction first operand 1...50, second 1...first.
- Multiplication operands 1...10. Division chooses answer 1...10 and a divisor
  1...answer, then uses answer × divisor as the dividend.
- Stage correct-answer counts: 10, 10, 5, 5, then indefinite mixed operations.
- Three lives, ten points per correct hit, four distinct choices per wave.
- Wrong hit removes that meteor and a life, retaining the question.
- Meteors advance toward a mothership. Desktop controls are WASD and mouse.
- Source references a `scores_list` file not present in the cloned root listing.

Prototype adaptations: portrait layout, vertical movement lane, direct target
tapping, a wave-level defense-line penalty, and freezing a wave during its
0.3-second projectile animation. This replaces the original frame-dependent
movement/damage timing with elapsed-time movement and once-only rule events.
